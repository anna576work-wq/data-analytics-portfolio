### [Автоматизация финансового учёта преподавателей — Google Sheets](projects/tutor-finance-analytics/)

Построила связанную модель данных, реализовала контроль корректности операций и аналитическую отчётность. В портфолио представлена обезличенная демонстрационная версия.
